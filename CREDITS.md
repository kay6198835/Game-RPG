## If an asset cannot be redistributed

Options, in order of preference:

1. Replace it with a permissively-licensed equivalent (Kenney.nl, OpenGameArt, itch.io free packs)
2. Remove it from the repository, add its folder to `.gitignore`, and document in the README
   that the art must be supplied separately
3. Keep the repository private and share a build link instead of source
