# BUG-120

**Title**: Item stat-modifier effects apply nothing — `StatModifierEffect.Apply()` only resolves the receiver, both concrete menus point at `abstract` classes, and the two existing item effect assets now reference an abstract script
**Severity**: S2 (stat items picked up in a run silently do nothing)
**Priority**: 2
**System**: Items (`ItemEffectDefinition/`)
**Found by**: weekly wrap-up code review 2026-10-31 (NOTE-20261031-5) at `sprint-20` `2276049e`
**Status**: Open — confirmed by reading code and asset YAML; not yet observed in Play Mode
**Fixed in**: —

## Description

`786c031b` "add effec component" (2026-10-25) replaced `StatModifierEffectDefinition` with:

- `Assets/Script/System/Item/ItemEffectDefinition/StatModifierEffect.cs:10-13` — `abstract`; `Apply()`
  calls `TryGetCapability(out effectReceiver)` and stops. No `AdjustMaxStats()` /
  `AdjustCurrentStats()` call exists anywhere under `ItemEffectDefinition/`.
- `ModifierMaxStatsEffect.cs:5-6` and `ModifierCurrentStatsEffect.cs:5-6` — both carry
  `[CreateAssetMenu]` **and** `abstract`, so the menu entries cannot create an asset, and neither
  overrides `Apply()`.
- `StatModifierEffect.cs.meta` keeps the old GUID `fe7649a572d1f5b449506818fb67b2ec`, so
  `Assets/SO/Item/Effect/New Stat Modifier Effect Definition.asset` and `… - Copy.asset` now bind to
  an abstract `ScriptableObject` type, which Unity cannot instantiate (the asset loads broken / as a
  missing script). Their authored list is stored under `authoredModifiers`, which the field no longer
reads (BUG-121).

Net effect: any item whose effect list holds a stat modifier changes no stat on pickup.
Also: unused `using Unity.VisualScripting` in all three files.

⚠️ The owner's working tree had uncommitted edits in the effect area at triage time; re-read after the
next push.

## Expected fix (owner)

Make `ModifierMaxStatsEffect` / `ModifierCurrentStatsEffect` concrete and have them call
`effectReceiver.AdjustMaxStats(group, null, <item instance>)` /
`AdjustCurrentStats(group, null)`; re-author the two item effect assets against the concrete types.
