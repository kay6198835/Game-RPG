# BUG-123

**Title**: `CoinModifierEffect` is `abstract` with no `[CreateAssetMenu]` — no coin item effect can be authored, so `WalletComponent.AddCoins()` has no reachable item path
**Severity**: S3 (planned coin pickup cannot work; no error, no crash)
**Priority**: 3 (fix together with BUG-120 — same file family, same shape)
**System**: Items (`ItemEffectDefinition`), Wallet
**Found by**: `/doc-sync --auto` 2026-10-31 (inbox note NOTE-20261031-10); confirmed by the 2026-11-07 wrap-up triage
**Status**: Open — confirmed by reading code
**Fixed in**: —

## Description

`Assets/Script/System/Item/ItemEffectDefinition/CoinModifierEffect.cs:6` (at `sprint-21` `acacdf6c`):
`public abstract class CoinModifierEffect : ItemEffectDefinitionSO`, with no `[CreateAssetMenu]`.
Unity cannot create an asset of an abstract `ScriptableObject`, so no item can carry a coin effect,
and `WalletComponent` (`IWallet.AddCoins()`) is never reached from an item pickup.

BUG-120 covers the stat-modifier effects (`StatModifierEffect`, `ModifierMaxStatsEffect`,
`ModifierCurrentStatsEffect` — `abstract` with menus on them); the coin effect is a separate class
and was not part of that bug.

## Expected fix (owner)

Make the class concrete, add `[CreateAssetMenu(menuName = "Item SO/Effect/Coin")]`, implement
`Apply()` through `IWallet`, and author one coin item asset. Design reference: `design/gdd/item-system.md`
(coin / Wallet planned).

## How to verify

Create a coin effect asset from the menu, attach it to an item, pick the item up in Play Mode: the
wallet value rises.
