**Fixed in**: —

## Description

`8005d27e` "update animation, asset" (2026-11-21) changed
`Assets/Script/Character/Base/NegativeReceiverBase.cs:9` from

`NegativeReceiverBase<TCore> : CoreComponentBase<TCore>, INegativeReceiver`

to

`NegativeReceiverBase<TCore> : CoreComponentBase<TCore>, INegativeReceiver<TCore>`

and added the new generic interface `INegativeReceiver<TCore>` (only `InvicisibleHurtbox(bool)`) in
`Assets/Script/Interface/INegativeReciver.cs:10-13`. The class still has a public `TakeDamage()`, but
it no longer implements `INegativeReceiver`. The only subclasses are `NegativeReciver` (player) and
`EntityNegativeReciver` (enemies).

Every damage dealer finds its target through the non-generic interface:

- `Assets/Script/Weapons/MeleeWeapon/MeleeWeapon.cs:31`
- `Assets/Script/Weapons/RangeWeapon/RangeWeapon.cs:75`
- `Assets/Script/System/Abilities/Effects/SpawnProjectileEffect.cs:26`, `SpawnSummonEffect.cs:36`
- `Assets/Script/System/Abilities/Runtime/SpawnMono/DamageArea.cs:27`, `DamagesInManyPos.cs:69`,
  `SpawnProjectileBase.cs:40`

So no hit reaches any character. Only `TrainingDummy` and `QAProbeTarget` (FastTest) still implement
`INegativeReceiver` directly.

QA evidence (run `20261121-2106`): QA-ENT-08 "player HP unchanged after 3-4 attacks" for all 10 enemy
roles; QA-VIT-15 "neither `NegativeReciver` nor `EntityNegativeReciver` is assignable to
`INegativeReceiver`". The owner's `Editor-prev.log` (2026-11-21 16:38) also showed the mid-edit
`QAPlayerRig.cs(28,23): CS0266 Cannot implicitly convert 'NegativeReciver' to 'INegativeReceiver'`.

Same commit, same fix pass (STATIC, wrap-up review 2026-11-21):

- `NegativeReceiverBase.cs:8` adds `[RequireComponent(typeof(BoxCollider2D))]` and resolves `hurtbox`
  with `GetComponent<BoxCollider2D>()` in `Start()` (`:22`). `InvicisibleHurtbox()` (`:42`) has no null
  check, so a call before `Start()` throws, and on a GameObject with more than one `BoxCollider2D` it
  toggles whichever comes first, not necessarily the hurtbox.

## Fix direction (owner)

`public abstract class NegativeReceiverBase<TCore> : CoreComponentBase<TCore>, INegativeReceiver, INegativeReceiver<TCore> where TCore : CoreBase`
(keep both interfaces). Guard `hurtbox` (`if (hurtbox != null)`) or resolve it in `Awake()`.
