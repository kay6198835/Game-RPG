# BUG-121

**Title**: `StatModifierGroup.authoredModifiers` renamed `statsModifiers` with no `[FormerlySerializedAs]` — the Paladin weapon bonus, Blessed Slash recovery and both item effects load empty
**Severity**: S2 (authored gameplay data silently lost on load; no error, no log)
**Priority**: 1 (one attribute; third occurrence of the BUG-105 / BUG-108 rename pattern)
**System**: Stats (`StatModifierGroup`), Weapons, Abilities v2, Items
**Found by**: weekly wrap-up code review 2026-10-31 (review-flow R3.5) at `sprint-20` `2276049e`
**Status**: Open — confirmed by reading code and asset YAML; not yet observed in Play Mode
**Fixed in**: —

## Description

`343a3830` "coding" (2026-10-29, on `sprint-20` through merge `2276049e`) changed
`Assets/Script/System/StatSystem/StatModifierGroup.cs:23-24` from

```
[FormerlySerializedAs("modifiers")]
private List<StatModifier> authoredModifiers
```

to `private List<StatModifier> statsModifiers` with no `[FormerlySerializedAs("authoredModifiers")]`.
The doc comment above the field (`:21-22`) still claims `FormerlySerializedAs` preserves the data.

Assets still storing the old key (`git grep authoredModifiers -- Assets/SO`), non-empty ones in bold:

- **`Assets/SO/Weapons/PaladinWeapon/SnS_Stat.asset:25`** — the Paladin sword's STR / PhysicalDamage bonus
- **`Assets/SO/Skill/Paladin/Ability/Blessed Slash/Effect/Paladin Recovery Reduction Stats Effect.asset:18`**
- **`Assets/SO/Item/Effect/New Stat Modifier Effect Definition.asset:16`** and **`… - Copy.asset:16`**
- empty: `EnemySnS_Stat.asset`, `Range Weapon Stats.asset`, `Avatar of Light/Effect/Recovery Stat Effect.asset`

Unity loads `statsModifiers = []` for all of them. Only `Gain For Time Effect.asset` and Blessing's
`Paladin Recovery Reduction Stats Effect.asset` were re-saved with the new key. Side effect: the
Paladin weapon no longer leaks its modifiers into the player stat assets (BUG-115), because it has
none to leak.

## Expected fix (owner)

Add `[FormerlySerializedAs("authoredModifiers")]` to `statsModifiers` (keep the attribute
permanently), then re-save the listed assets. Do not re-save before adding the attribute.

## How to verify

Inspect `SnS_Stat.asset`: the Stat Modifier Group shows its two modifiers. In Play Mode, equip the
Paladin sword and open the stats panel (C): STR and PhysicalDamage include the weapon bonus.
