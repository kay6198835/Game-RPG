# BUG-085

**Title**: `NotDeadCondition.IsMet()` body is commented out — the condition unconditionally returns `true`
**Severity**: S3 (dormant — the condition exists as a class but no live `.asset` references it)
**Priority**: 3
**System**: Abilities v2 / Conditions
**Found by**: Documentation/source re-verification pass, 2026-09-22 (branch `main`, HEAD `d17fcc5`, merge of `e2cb75e`)
**Status**: ✅ FIXED 2026-09-22 by `2a83469` — `NotDeadCondition.cs` and its `.meta` deleted; `Assets/Script/System/Abilities/Conditions/` is now empty. See the re-verification at the end of this file. *Previous status line:* Open — CONFIRMED

## Description

`Assets/Script/System/Abilities/Conditions/NotDeadCondition.cs:6-11`:

```csharp
public override bool IsMet(AbilityContext context)
{
    // if (context?.Caster?.Health == null) return false;
    // return !context.Caster.Health.IsDead;
    return true;
}
```

The class carries `[CreateAssetMenu(menuName = "Game/Abilities/Conditions/Not Dead")]`, so a
designer can author an asset from it at any time and it will silently gate nothing. The commented
code refers to `context.Caster.Health`, a member that `IAbilityOwner` does not have — the condition
was written against an older owner interface and was never ported when the framework left
`prototypes/`.

Currently dormant: the only condition asset in the project is
`Assets/SO/Skill/Conditions/Has Enough Mana Condition.asset`
(GUID `02cbacd1d0342774abb852a2ed63f9b4`), and no `NotDeadCondition` asset exists.

## Suggested Fix

Either implement it against the current interface —

```csharp
public override bool IsMet(AbilityContext context)
{
    if (context?.Services?.Vital == null) return false;
    return context.Services.Vital.GetCurrentStatValue(StatType.HP) > 0f;
}
```

(note: that read is itself unguarded today — see **BUG-070**) — or delete the class so the
`CreateAssetMenu` entry stops offering a no-op condition to designers. Do not leave it as a
commented stub: an always-true condition is indistinguishable from a working one in the Inspector.

- A correct implementation depends on **BUG-070** being fixed first.
