## Description

`git log --since=2026-07-03` shows three directories under `Assets/Script/` that are
actively developed but absent from `CLAUDE.md`'s Repository Layout section:

- `Assets/Script/Character/Base/` — `BaseEntity.cs`, `CoreBase.cs`, `CoreComponentBase.cs`,
  `Interface/ICore.cs`, `Interface/ICoreComponent.cs`, `StateMachine.cs`, `IState.cs`,
  `DirectionResolver.cs`, `StatusAnimation.cs`. This is a new shared component-hub layer
  sitting underneath both `Core.cs` (player) and `EntityCore.cs` (enemy).
- `Assets/Script/System/Pathfinding/` — `Algorithm/` (AStar, Heuristic, PriorityQueue), `Data/`
  (Node, Path, SearchNode, PathRequest), `Grid/` (GridBuilder, PathfindingGrid),
  `PathRequestManager.cs`, `Utility/`.
- `Assets/Script/System/PoolableService/` — `ObjectPoolManager.cs`, `Pool.cs`, `PoolMember.cs`. This
  appears to supersede `Assets/Script/Pooling/ObjectPooling.cs` (referenced by tech-debt
  item TD-033), which no longer exists on disk — `TD-033`'s file path is now stale.

None of these three directories, nor the architectural shift they represent, appear in
CLAUDE.md, in any GDD, or in an ADR. `engine-code.md` requires "New capabilities must be
expressed as interfaces first" and restricts component hubs to `Core.cs`/`EntityCore.cs` —
`CoreBase`/`CoreComponentBase` is a new hub layer that predates/underlies both and was
never run through that contract.

## Impact

- Any agent or contributor orienting from CLAUDE.md alone will not know these systems
  exist, misjudge the actual scope of `Character/` and `Enemy AI`, and may duplicate or
  conflict with `Pathfinding`/`Poolable` when implementing new features.
- `TD-033` in `docs/tech-debt-register.md` points at a file (`Assets/Script/Pooling/ObjectPooling.cs`)
  that has been removed — the register entry needs to be reconciled against `Poolable/`.
- This is very likely the concrete substrate of the "off-plan work" pattern the last 7
  bug-triage cycles have flagged (commits like "coding", "fix", "fixing" touching
  `EntityMovement.cs` + `Pathfinding/*` with no story ID) — the work is real and
  functioning, it just was never documented as its own system.

## Suggested Fix

1. Run `/doc-sync` (or manually update CLAUDE.md's Repository Layout) to add
   `Character/Base/`, `Pathfinding/`, and `Poolable/` with the same level of detail as
   existing entries.
2. Update `TD-033` in `docs/tech-debt-register.md` to point at `Poolable/` (or close it
   if `Poolable/` already resolves the concern it described).
3. Decide whether `CoreBase`/`CoreComponentBase` warrants its own short ADR (it changes
   the component-hub contract `engine-code.md` currently describes as closed to
   `Core.cs`/`EntityCore.cs` only) — flagging for owner decision, not resolving here.
