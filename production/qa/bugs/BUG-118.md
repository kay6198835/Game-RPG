## Description

`Assets/Script/System/Abilities/Effects/RecoveryReductionPerTimeForDuration.cs:11` calls
`effectReceiver.AdjustCurrentPerTimeForDuration(...)`, and
`Assets/Script/Character/Base/EffectReceiverBase.cs:98-101` implements it as
`throw new System.NotImplementedException();`. A working tick loop exists beside it
(`ReductionPerTimeForDuration()` / `ReductionPerTime()`, `:66-80`) but is not on the interface and has
no caller.

`git grep` of the effect's script GUID (`4b98fd5a8dcd82b469f4a02cd1a9991f`) under `Assets/SO` returns
0 hits, so nothing throws today. The comment at `:65` ("BUG-071: the iterators below are built but
never started") is stale — `:68` does start the coroutine; the BUG-071 residual (recursion through the
public wrapper, no handle to stop it) moved here unchanged.

## Expected fix (owner)

Implement `AdjustCurrentPerTimeForDuration()` with the existing tick loop (keep one `Coroutine`
handle so it can be stopped on death / despawn), or remove the effect's `[CreateAssetMenu]` until it
is implemented.
