# BUG-125

**Title**: Melee hits add the attack-stage damage twice — `WeaponHolderBase.CalculateCurrentDamage()` already adds `CurrentStage.attackDamage`, then `Weapon.FinalDamage()` (new in `38d40925`) adds it again
**Severity**: S2 (every melee hit, player and enemy, deals more than designed; the crit bonus is computed before the second add)
**Priority**: 1 (one-line fix; it skews every combat-balance reading taken this sprint)
**System**: Weapons / damage chain (`Weapon`, `MeleeWeapon`, `WeaponHolderBase`)
**Found by**: automated QA run `20261114-2329` / `20261114-2357`, case QA-CMB-01.Paladin (inbox note NOTE-20261115-1), re-read at `sprint-22` `ff7f3ecb` by the 2026-11-15 wrap-up
**Status**: Open — confirmed at runtime by the automated QA run (2 of 2 runs) and by reading code
**Fixed in**: —

## Description

`WeaponHolderBase.CalculateCurrentDamage()` (`Assets/Script/Character/Base/WeaponHolderBase.cs:90-98`)
returns `PhysicalDamage + weapon.CurrentStage.attackDamage`, plus a crit bonus on a crit roll, and
passes it to `weapon.OnActivate(damage)` (`:81`).

`38d40925` "paladin combo attackcc" (2026-11-08, merged into `sprint-22` as S22-F1) added:

```
public virtual float FinalDamage(float damage)
{
    return damage + currentStage.attackDamage; ;
}
```

(`Assets/Script/Weapons/Weapon.cs:67-70`), and `MeleeWeapon.OnActivate()` calls
`receiver.TakeDamage(FinalDamage(finalDamage), …)` (`Assets/Script/Weapons/MeleeWeapon/MeleeWeapon.cs:33`).
The stage damage is therefore added twice. QA-CMB-01.Paladin measured a stage-1 sword hit at 72.4
against 64.4 expected (PhysicalDamage 56.4 + stage 8).

The QA run mapped the case to BUG-105 ("regression?"). It is not a BUG-105 regression: the stage value
now loads correctly (`fbab752a`), and it is counted twice.

## Expected fix (owner)

Keep the stage term in one place — either remove it from `CalculateCurrentDamage()` or make
`FinalDamage()` return `damage` — and decide whether the crit multiplier should include the stage
damage. Check `RangeWeapon` for the same shape (ranged hits use `currentStage.attackDamage` only,
NOTE-20261104-4).

## How to verify

QA-CMB-01.Paladin passes (hit = PhysicalDamage + stage damage). In Play Mode, a stage-1 sword hit
on a 0-Defense dummy reduces HP by PhysicalDamage + 8.
