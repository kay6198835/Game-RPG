# BUG-086

**Title**: `PlayerDeathState.LogicUpdate()` re-emits `ON_PLAYER_DEATH` every frame — the event fires unbounded, not once
**Severity**: S2 (event-bus contract violation; currently harmless only because the event has no subscribers)
**Priority**: 2
**System**: Player / State machine / Event bus
**Found by**: Documentation/source re-verification pass, 2026-09-22 (branch `main`, HEAD `d17fcc5`, merge of `e2cb75e`)
**Status**: Open — CONFIRMED

## Description

`Assets/Script/Character/Player/States/PlayerDeathState.cs:14-20`:

```csharp
public override void LogicUpdate()
{
    if (Status == StatusAnimation.EndRangeTrigger)
    {
        EventManager.Emit(EventID.ON_PLAYER_DEATH);
    }
}
```

`LogicUpdate()` is ticked every frame from `BaseEntity.Update()`. The method:

- does not call `base.LogicUpdate()`
- does not write a new value to `Status` to consume the trigger
- does not change state

so once the death animation reaches `EndRangeTrigger`, `Status` stays at `EndRangeTrigger` forever
and `Emit(ON_PLAYER_DEATH)` fires on every subsequent frame, indefinitely.

This directly violates the contract in `.claude/rules/manager-event-code.md`:

> `Status` is durable state, not a one-frame pulse: the state that acts on a value is responsible
> for writing a new one to consume it

Compare the enemy side, which gets this right: `EntityDeathState` emits `ON_ENEMY_DEATH` on
`EndRangeTrigger` and the entity is despawned, terminating the tick.

The damage is currently invisible because `ON_PLAYER_DEATH` has zero subscribers (**BUG-087**).
The moment anything subscribes — a `GameManager`, a death UI, a run-statistics counter — it will be
invoked at frame rate.

## Reproduction

1. Enter Play Mode, let the player's HP reach 0.
2. Register any listener on `EventID.ON_PLAYER_DEATH` (or add a `Debug.Log` at
   `PlayerDeathState.cs:18`).
3. Observe the log repeating every frame rather than once.

## Suggested Fix

Consume the trigger, mirroring what every other player state does:

```csharp
public override void LogicUpdate()
{
    base.LogicUpdate();
    if (Status != StatusAnimation.EndRangeTrigger) return;
    SetAnimationStatus(StatusAnimation.End);
    EventManager.Emit(EventID.ON_PLAYER_DEATH);
}
```
