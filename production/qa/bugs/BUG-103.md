# BUG-103

**Title**: `RangeWeapon.nextFireTime` is written but never read — `RangeAttackSO.RecoveryTime` has no effect; `OnDrawGizmosSelected` draws from a wrong point
**Severity**: S3 (a tuning knob silently does nothing; fire rate is bounded only by the attack animation)
**Priority**: 3 (one-line gate in `CanAttack()`; verify with the ranged weapon in Play Mode)
**System**: Weapons / Ranged
**Found by**: `/doc-sync --auto` 2026-10-09 (NOTE-20261009-10, one of the three unfiled defects listed in BUG-101); confirmed by weekly wrap-up triage 2026-10-10 at `sprint-18` HEAD `c6cbc57a`
**Status**: Open — static analysis; confirm in Play Mode
**Fixed in**: —

## Description

`Assets/Script/Weapons/RangeWeapon/RangeWeapon.cs`:

- `:11` declares `private float nextFireTime;`
- `:67` writes it at the end of `OnActivate()`: `nextFireTime = Time.time + stage.RecoveryTime;`
- Nothing reads it. `CanAttack()` (`:22-24`) is
  `base.CanAttack() && StatsRange != null && _objecPoolService != null` — no time term — and
  `CanChain()` (`:26-30`) builds on `CanAttack()`.

So `RangeAttackSO.RecoveryTime`, the authored cooldown between shots, is dead data. With
`StatsRange.AutoFire` the weapon chains as fast as the attack animation allows.

Secondary, same file:

- `OnDrawGizmosSelected()` (`:79-86`) tests `firePoint != null` on a `Vector2` (always true) and draws
  `firePoint + firePoint * currentStage.attackRange` — scaling the *world position* by the range instead
  of adding an aim direction. The gizmo line points away from the world origin, not along the shot.

## History

`nextFireTime` predates the 2026-09-28 rewrite (`797a5628`, `7c637c0e`); the read side was lost when
`CanAttack()` was rewritten. It was mislabelled "BUG-093" in `CLAUDE.md` on 2026-10-05 (see BUG-101).

## Expected fix (owner)

Add `&& Time.time >= nextFireTime` to `CanAttack()` (or to `CanChain()` only, if the first shot must
never be gated — a design choice). Gizmo: draw from `holder.OwnerTransform.position` along
`aim.AimDirection * attackRange`, or delete it.

## How to verify

Play Mode: equip the ranged weapon, set `RecoveryTime` to 2 s on stage 1, hold attack — shots must be
at least 2 s apart.
