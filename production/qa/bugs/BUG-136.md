# BUG-136

**Title**: `Trap` never fires for a correctly authored target mask, and throws `NullReferenceException` when it does — it compares a `LayerMask` with a layer index, and the scene instance is never `Launch()`ed, so `_context` / `_callback` stay null
**Severity**: S3 (the trap in `MainGamePlay` does nothing today; once the mask check is fixed every trigger throws)
**Priority**: 3 (two-line fix in one class plus a decision on how a scene-placed trap gets its context; not on the demo path yet)
**System**: Abilities / Spawn effects (`Trap`, `SpawnEffectMono`)
**Found by**: daily standup review of `f2a580b2` (inbox note NOTE-20261126-1, updated 2026-11-27); confirmed by the 2026-11-28 wrap-up triage (re-read at `sprint-24` `d3e5418e`)
**Status**: Open — confirmed by reading code; not observed in Play Mode
**Fixed in**: —

## Description

`Assets/Script/System/Abilities/Runtime/SpawnMono/Trap.cs` (`f2a580b2`, edited in `8377ebaf`), at `d3e5418e`:

1. `:17` `if (_targetMask != other.gameObject.layer) return;` compares a `LayerMask` (bit mask, e.g.
   `256` for layer 8) with a layer index (`8`). The check passes only when the mask value happens to
   equal the layer number, so a correctly authored mask never lets the trap fire. Same shape as the
   earlier NOTE-20261115-6.
2. `Trap` derives from `SpawnEffectMono`, whose `_context` / `_callback` are set only in
   `Launch(lifetime, context, callback)` (`BaseController/SpawnEffectMono.cs:10-15`). The only use of
   `Trap.prefab` (guid `53e07ce6…`) is a placed instance in `Assets/Scenes/Main/MainGamePlay.unity`;
   nothing calls `Launch()` on it. So a passing trigger runs `_context.Target = other;` (`:18`) on a
   null `_context` and throws.
3. `_damage` (`:8`) is serialized but never read.

## Fix direction (owner)

- `if ((_targetMask.value & (1 << other.gameObject.layer)) == 0) return;`
- Decide how a scene-placed trap gets its `AbilityContext` and payload: spawn it through a spawn
  effect (`Launch`), or give it its own damage path (e.g. `IEffectReceiver.ApplyDamage(_damage, …)`)
  and drop the `SpawnEffectMono` dependency. Guard `_callback?.Invoke(...)` either way.

## How to verify

Play Mode on `MainGamePlay`: the player walks onto the trap → it damages the player once per entry, no
Console exception; an object on a layer outside `_targetMask` does not trigger it.
